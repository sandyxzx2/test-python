# 安卓自动输入脚本

这个脚本可以在安卓手机上自动在聊天应用的输入框中输入"你好，美女"。

## 安装步骤

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

或者直接安装：

```bash
pip install uiautomator2
```

### 2. 连接安卓设备

有两种连接方式：

#### 方式A: USB连接（推荐）
1. 用USB线连接手机到电脑
2. 在手机上启用"USB调试"（开发者选项 -> USB调试）
3. 在手机上允许USB调试授权

#### 方式B: WiFi连接
1. 确保手机和电脑在同一WiFi网络
2. 在手机上安装并打开"ATX"应用（运行初始化命令时会自动安装）

### 3. 初始化设备

```bash
python -m uiautomator2 init
```

这个命令会：
- 在手机上安装ATX应用（用于自动化控制）
- 配置设备连接

### 4. 运行脚本

#### 基本使用
```bash
python auto_input.py
```

#### 调试模式（查看界面元素）
如果输入框定位失败，可以先运行：
```bash
python auto_input.py dump
```

这会导出当前界面的UI结构到 `ui_dump.xml`，你可以查看文件找到输入框的准确信息。

## 使用方法

1. **打开聊天应用**：在手机上打开目标聊天应用，进入聊天界面
2. **运行脚本**：在电脑上运行 `python auto_input.py`
3. **查看结果**：脚本会自动在输入框中输入"你好，美女"

## 脚本说明

脚本使用了多种方法尝试定位输入框：

1. **方法1**：通过占位符文本"文明聊天"定位
2. **方法2**：通过EditText类名定位（选择最底部的输入框）
3. **方法3**：通过屏幕坐标定位（点击屏幕底部中间位置）

如果所有方法都失败，脚本会提示你运行 `dump` 命令查看界面结构。

## 自定义修改

如果需要修改输入的文本，编辑 `auto_input.py` 文件，找到所有 `"你好，美女"` 的地方，替换为你想要的文本。

## 常见问题

### Q: 提示"设备连接失败"
A: 
- 检查USB调试是否已启用
- 尝试运行 `adb devices` 查看设备是否被识别
- 如果是WiFi连接，确保手机和电脑在同一网络

### Q: 找不到输入框
A:
1. 运行 `python auto_input.py dump` 查看界面结构
2. 打开 `ui_dump.xml` 找到输入框的资源ID或文本
3. 修改脚本中的定位方法，使用找到的资源ID

### Q: 输入框定位到了但输入失败
A:
- 确保输入框已获得焦点（脚本会自动点击）
- 检查应用是否有输入限制
- 尝试增加等待时间（修改 `time.sleep()` 的值）

## 注意事项

- 不同设备的屏幕分辨率不同，坐标定位可能需要调整
- 某些应用可能有反自动化机制，需要特殊处理
- 建议在测试环境中先验证脚本功能
